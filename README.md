# JiTap Website

Official marketing website source repository for **JiTap**, an AI-powered real-time local services network in Kenya.

**Brand:** ASK • MATCH • BUZZ  
**Stack in prepared source archive:** Next.js 15, React 19, TypeScript, Lucide React and Zod.

## Source import status

The full website project has been generated separately as **JiTap_Website_Master_Source_v2.zip** (43 source/assets files, approx. 5.5 MB). **The ZIP contents have not yet been imported into this GitHub repository.** This repository is initialized for that import.

Upload the **contents of the `jitap-website/` directory inside the ZIP** into the repository root (not the outer folder). Include `src/`, `public/`, `package.json`, `tsconfig.json`, `.env.example` and project documentation. Do not upload `node_modules/`, `.next/`, `.env`, or credentials.

After import:

```bash
npm install
npm run typecheck
npm run build
npm run dev
```

### Launch safety

The website includes demonstration interfaces. Provider matching, BUZZ/dispatch, real-time ETA, payments and production intake services **are not active without backend configuration and verification**. Provider/customer intake must not report success without actual delivery. Legal policy pages require review.
